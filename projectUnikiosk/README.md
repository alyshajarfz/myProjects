# UNIKIOSK ORDERING SYSTEM

UniKiosk is a modern and efficient food kiosk system developed using both C and Java programming languages, designed to meet the fast-paced needs of a university environment. This system aims to streamline food ordering and management processes, providing convenience for students, staff and vendors alike.

The system enables users to:

    - Handle orders by creating new orders and displaying a full menu of available food and drink items.
    - Manage customer data by adding new customers and viewing customer details.
    - Calculate the total purchase amount for each transaction.
    - Automatically apply discounts based on valid promotional codes such as JASIN, enhancing customer satisfaction.
    - Generate detailed receipts for all purchases, ensuring transparency and easy record-keeping.

The system is designed to reduce wait times, improve order accuracy and support the high volume of transactions typical in a university's environment. 
By digitizing and automating key aspects of food ordering, UniKiosk enhances the overall dining experience on campus, making it faster, easier and more reliable for everyone involved.
