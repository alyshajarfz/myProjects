## FOOD ORDERING SYSTEM 

The food ordering system, eMenu Taste Haven Cafe is designed to streamline food ordering for both customers and administrators in a restaurant. I created this system using HTML, CSS, JavaScript and PhpMyAdmin to handle server-side operations and store data in a database running on XAMPP. This setup enables a seamless and dynamic ordering experience with real-time data management.

Customers are able to:

    - Easily browse the menu
    - Customize their orders
    - Place orders through a responsive interface
    - Use the system as registered users or guests

Administrators have the capability to:

    - Manage customer details, menu categories and dishes
    - Monitor and control orders and payments in real time
    - Promptly update order and payment status to ensure timely service

Overall, the eMenu Taste Haven Cafe system enhances customer convenience and operational efficiency by digitizing ordering and management processes. This minimizes errors, speeds up service and improves the overall dining experience.
